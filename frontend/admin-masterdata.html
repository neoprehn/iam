Die Seite strukturiert alle 9.4-Themen zentral. Aktuell funktionsfaehig: Kritikalitaetskatalog, Risikoabdeckung-Statistik, Katalogvorschau fuer Module/Querytypen/Reason-Codes.
Wichtig: Masterdata (z. B. Kritikalitaetsstufen) gelten global ueber alle Filtersets/Rulesets und werden zentral referenziert.
Modus: Anzeige (oben erst auf Aendern klicken)

Risikokatalog inhaltlich befuellen

in Arbeit
Status je Ruleset fuer Query-/SoD-Risiko-Felder (risk/riskType/riskLevel/riskStatus).

Kritikalitäts-Stammdaten

aktiv
Stufen, Labels, Rang, Farbe und KRI-Score. Interne IDs sind technische Schluessel, werden automatisch berechnet und sind nicht direkt editierbar.
IDLabelRangFarbeKRI

Kritikalitaet prominent an Einzelfilter/SoD

offen
UI-Badge-Politur in Katalog/Auswahl/Ergebniszeilen. Technische Basis (Katalog) ist vorhanden.

Reason-Code-Stammdaten (SoD)

in Arbeit
Technische IDs + Label fuer SoD-Reason-Codes.
IDLabel

Modul-Stammdaten

in Arbeit
ID ist technisch und nicht direkt editierbar (wird aus dem Label gebildet).
IDLabel

Querytyp-Stammdaten

in Arbeit
ID ist technisch und nicht direkt editierbar. Label wird ueber den Code gefuehrt; Beschreibung erlaeutert den Typ (z. B. AO = Audit Optional, JAP = Jahresabschluss).
IDLabelBeschreibung

Dropdowns statt Freitext

aktiv
Das ist keine eigene Stammdatenfunktion, sondern die Nutzung der Stammdaten im Query Management. Stand: fuer Kritikalitaet, Modul, Querytyp und Reason-Code umgesetzt.

Authorizations/TCodes im Editor (v2)

offen
Der Aufbau-Tab ist noch read-only. Bearbeitungs-UI fuer verschachtelte Objekt/Feld/Wert-Listen steht aus.

USOBT-gestuetzter Query-Builder (v2)

offen
Geplant: Query-Erstellung per Transaktion -> Berechtigungsobjekt statt Freitext.

Query -> System-Typ-Zuordnung (v2)

offen
Geplant: Stammdatenblatt fuer Zuordnung zu R/3, S/4HANA und weiteren Quellsystemen.

Filterset-/Konnektor-Import weitere Systeme (v2)

offen
Geplant: S/4HANA, Azure AD/Entra, Microsoft Dynamics, Salesforce.
